# E-Commerce Sales & Customer Analytics

## Project Overview

This project analyzes e-commerce sales data to understand sales performance, customer behavior, product performance, and country-wise revenue.

The project follows a complete data analytics workflow:

1. Data cleaning using Python
2. Exploratory Data Analysis using Pandas and Matplotlib
3. Data storage and analysis using MySQL
4. Business analysis using SQL
5. Interactive dashboard creation using Power BI
6. Business insights and recommendations
7. Project documentation using GitHub

The goal of this project is to convert raw transaction data into meaningful business insights that can help a company improve revenue, customer retention, product performance, and marketing decisions.

---

The main objectives of this project are:

## Dataset Information

The dataset contains e-commerce transaction records.

Each row represents a product transaction made by a customer.

### Main Columns

| Column      | Description                                |
| ----------- | ------------------------------------------ |
| InvoiceNo   | Unique invoice or transaction number       |
| StockCode   | Product code                               |
| Description | Product description                        |
| Quantity    | Number of products purchased               |
| InvoiceDate | Date and time of the transaction           |
| UnitPrice   | Price of one product                       |
| CustomerID  | Unique customer identifier                 |
| Country     | Customer's country                         |
| Revenue     | Total revenue generated by the transaction |

### Revenue Calculation

Revenue was calculated using:

```text
Revenue = Quantity × UnitPrice
```

## Key Performance Indicators

The following KPIs were created in Power BI using DAX:

```DAX
Total Revenue = SUM(sales[Revenue])
```

```DAX
Total Orders = DISTINCTCOUNT(sales[InvoiceNo])
```

```DAX
Total Customers = DISTINCTCOUNT(sales[CustomerID])
```

```DAX
Total Products = DISTINCTCOUNT(sales[StockCode])
```

```DAX
Total Quantity = SUM(sales[Quantity])
```

```DAX
Average Order Value =
DIVIDE([Total Revenue], [Total Orders])
```

## Challenges Faced and Solutions

### MySQL Connector Issue

The MySQL connector initially produced a client-library error while connecting Power BI to MySQL.

#### Solution

The data was connected to Power BI using an ODBC connection.

---

### Duplicate Column Error

During the data import process, duplicate column errors occurred.

#### Solution

The table structure and column names were checked and corrected before importing the cleaned data.

---

### Missing CustomerID Values

Some transaction records did not contain a CustomerID.

#### Solution

Missing CustomerID values were identified during data cleaning and were handled appropriately during customer-level analysis.

---

### MySQL Connection Loss

A connection-loss error occurred while working with a large dataset.

#### Solution

The MySQL service was restarted, the database connection was checked, and the data was imported again successfully.

---

### Large Dataset Performance

Some SQL queries took longer because the dataset contained more than 500,000 rows.

#### Solution

The analysis was divided into smaller queries and filters were used wherever required.
